# dotskills
Personal dotfiles for my AI coding agent: reusable skills to prepare, study and track development work. Built to grow with new skills over time.

## Skills

| Skill | What it does |
|---|---|
| [`adr`](adr/SKILL.md) | Writes or updates an Architecture Decision Record, in French. |
| [`dev-journal`](dev-journal/SKILL.md) | Runs a dev (feature, rework, bug fix) through a single Markdown journal, from the spec to the deployment. |
| [`study`](study/SKILL.md) | Study mode, invoked with `/study` only: explores a subject without touching the dev in progress. |

## Install

Clone into the personal skills folder of Claude Code:

```sh
git clone https://github.com/JAGFx/dotskills.git ~/.claude/skills
```

`synced/` is managed by Claude Code (skills synced from the claude.ai account) and stays out of the repo.
